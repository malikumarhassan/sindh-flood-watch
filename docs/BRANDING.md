# Branding reference

The green and cream masthead and supplied Sindh emblem were requested by the project owner. The unchanged supplied PNG is stored in `apps/web/public/branding/sindh-emblem.png` and `apps/mobile/assets/sindh-emblem.png`.

The product remains named **Sindh Flood Watch**. The interface explicitly identifies it as an independent information service and states that government endorsement is not implied. It does not label the application “Government of Sindh.” Confirm the required rights/authorization for public emblem use before launching an official-branded service; these changes are a local preview, not evidence of government affiliation.
